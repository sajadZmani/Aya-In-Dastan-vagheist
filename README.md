# آیا این داستان واقعیست؟ 🤥

یه بازی چندنفره‌ی تحت وب و فارسی برای دوستا (از ۲ نفر تا هر چند نفر که میزبان بخواد، حداکثر ۵۰)، روی گوشی یا لپ‌تاپ.
یه سؤال عجیب ولی **واقعی** با یه جای خالی میاد. هر کی یه جواب الکی ولی باورپذیر می‌نویسه،
بعد همه‌ی دروغ‌ها با جواب واقعی قاطی می‌شن و باید راستش رو پیدا کنی و هم‌زمان بقیه رو گول بزنی.
مثل «آش» بعضی بازیکن‌ها بچه‌ان، پس کلمه‌ی بد ممنوعه: اسم یا دروغی که کلمه‌ی بد داشته باشه قبول نمی‌شه.

## 📱 بازی با یک گوشی
اگه همه دور هم هستن، لازم نیست هر کی گوشی خودش رو بیاره. توی صفحه‌ی اول «بازی با یک گوشی» رو بزن، اسم
بازیکن‌ها (۲ تا ۲۰ نفر) و حالت و تعداد راندها رو انتخاب کن. بازی می‌گه «گوشی رو بده به سارا». سارا «من سارا
هستم» رو می‌زنه، دروغش رو می‌نویسه و گوشی رو به نفر بعدی می‌ده. حدس زدن هم همین‌طوریه. این حالت تایمر
نداره و افشاگری و جدول امتیاز رو همه با هم روی همون گوشی می‌بینن. اسم‌ها برای دفعه‌ی بعد ذخیره می‌شن.

## دو حالت بازی
- **🔤 کلمه‌ای:** یه سؤال عجیب ولی واقعی با جای خالی میاد و هر کی یه جواب الکی (یک تا سه کلمه) می‌نویسه.
- **📖 داستانی:** یه موضوع میاد (مثلاً «دنیای حیوانات» یا «قانون‌های عجیب») و هر کی یه داستان کوتاه الکی می‌سازه. بین همه‌ی داستان‌ها فقط یکی واقعیه.

توی حالت داستانی همه‌ی گزینه‌ها، چه داستان واقعی و چه دروغ بازیکن‌ها، به یه شکل خودمونی و بدون علامت نگارشی (بدون نقطه، ویرگول، گیومه، پرانتز و نیم‌فاصله‌ی مرتب) نشون داده می‌شن تا از ظاهر نوشته نشه فهمید کدوم رو سرور نوشته.

آخر هر راند جدول «رأی‌های این راند» نشون می‌ده هر جمله مال کی بود، چند رأی آورد و کیا بهش رأی دادن.

## تنظیمات (دست میزبان، توی لابی)
حالت بازی، تعداد راندها (۱ تا ۳۰، پیش‌فرض ۷)، زمان نوشتن (۱۵ تا ۳۰۰ ثانیه، پیش‌فرض ۶۰)،
زمان حدس زدن (۱۰ تا ۱۸۰ ثانیه، پیش‌فرض ۳۰) و حداکثر بازیکن (۲ تا ۵۰، پیش‌فرض ۱۰).

## روند بازی
1. **لابی:** یه نفر اتاق می‌سازه و یه کد ۴ حرفی می‌گیره (یا لینک دعوت رو می‌فرسته). میزبان 👑 تنظیمات رو انتخاب می‌کنه.
2. **نوشتن دروغ:** اگه کسی جواب درست یا خیلی نزدیک بهش رو بنویسه، پیام «این جواب درسته! یه دروغ دیگه بنویس» می‌گیره. دروغ‌های یکسان یکی می‌شن. اگه کسی چیزی ننوشت، یه دروغ آماده از بانک سؤال جاش ثبت می‌شه.
3. **انتخاب:** گزینه‌ها با ترتیب تصادفی میان. دروغ خودت قابل انتخاب نیست.
4. **افشاگری:** دروغ‌ها یکی‌یکی رو می‌شن («این دروغ علی بود و رضا و سارا گولش رو خوردن») و آخر از همه جواب واقعی. بعد جدول کامل رأی‌ها.
5. **امتیاز:** پیدا کردن جواب واقعی ۱۰۰۰، هر نفری که گول دروغت رو بخوره ۵۰۰. راند آخر دوبرابره.
6. جدول امتیاز بعد از هر راند، و آخر بازی برنده با کانفتی و دکمه‌ی «بازی دوباره».

## اجرای محلی
نیاز: Node.js نسخه‌ی ۱۸ یا بالاتر.

```bash
npm install
npm start
```
بعد `http://localhost:3000` رو باز کن.

## بانک سؤال
- سؤال‌ها از قبل جمع‌آوری شدن: ۱۵۱ سؤال کلمه‌ای و ۵۱۴ داستان واقعی برای حالت داستانی (۳۶۳ داستان در ۱۵ موضوع، به‌علاوه‌ی همه‌ی سؤال‌های کلمه‌ای به شکل جمله‌ی کامل). هر داستان یه دروغ آماده هم داره و ۵۰ داستان دروغ جدا هم بر اساس موضوع هست. توی حالت داستانی اگه بازیکن کم باشه، بازی چند تا دروغ آماده قاطی می‌کنه تا همیشه حداقل ۳ تا دروغ کنار داستان واقعی باشه. همه توی فایل `data/bank.json` هستن.
- توی یه اتاق هیچ سؤال یا داستانی تکرار نمی‌شه (حتی بعد از «بازی دوباره») تا وقتی کل بانک تموم بشه؛ بعد از اول شروع می‌شه.
- مرورگر بازیکن‌ها هیچ‌وقت کل بانک رو نمی‌گیره: فقط سؤال همون راند رو می‌بینه و جواب واقعی رو فقط موقع افشاگری.
- بانک ثابته: نه از توی بازی و نه دستی راهی برای اضافه کردن سؤال نیست.
- فهرست کلمه‌های بد هم به شکل متن توی کد نیست؛ فقط هش‌هاشون توی `lib/blocklist.json` هست.

## وصل شدن دوستان
**شبکه‌ی خونه (یه وای‌فای):** روی کامپیوتری که سرور روشه IP محلی رو پیدا کن (ویندوز: `ipconfig`، مک/لینوکس: `ifconfig` یا `ip a`)،
مثلاً `192.168.1.20`. دوستا توی مرورگر گوشی `http://192.168.1.20:3000` رو باز می‌کنن. اگه وصل نشد، به فایروال اجازه‌ی پورت ۳۰۰۰ رو بده.

**از طریق اینترنت (موقت):** یه تونل بساز، مثلاً:
```bash
npx cloudflared tunnel --url http://localhost:3000
```
یا `ngrok http 3000`. آدرس https که می‌ده رو برای دوستا بفرست.

## دیپلوی رایگان
سرور WebSocket همیشه‌روشن لازم داره، پس GitHub Pages (مثل آش) کار نمی‌کنه. گزینه‌های رایگان:
- **Render.com** (Web Service رایگان): با فایل `render.yaml` از New ← Blueprint ریپو رو انتخاب کن و Apply بزن (یا دستی: Build `npm install`، Start `npm start`). بعد از بی‌کاری می‌خوابه و اولین باز شدن چند ثانیه طول می‌کشه.
- **Koyeb** یا **Fly.io**: هر دو WebSocket رو پشتیبانی می‌کنن.

چون وضعیت اتاق‌ها توی حافظه‌ست، فقط **یه** نسخه از سرور اجرا کن. اتاق‌های خالی بعد از ۵ دقیقه پاک می‌شن.

## ساختار
- `server.js`: سرور Express و Socket.IO؛ مرجع وضعیت بازی و همه‌ی تایمرها
- `data/bank.json`: بانک سؤال‌ها و داستان‌ها
- `lib/questions.js`: آماده کردن بانک برای دو حالت بازی
- `lib/text.js`: نرمال‌سازی فارسی (ی/ي، ک/ك، فاصله و نیم‌فاصله، عددها)، تشخیص جواب نزدیک، فیلتر کلمه‌ی بد
- `public/`: رابط کاربری (HTML/CSS/JS ساده، فونت وزیرمتن، راست‌به‌چپ، mobile-first)

رفرش یا قطع و وصل شدن: با شناسه‌ی ذخیره‌شده توی `localStorage` با همون اسم و امتیاز برمی‌گردی. اگه میزبان بره، میزبانی به نفر بعدی می‌رسه.
