# آیا این داستان واقعیست؟ 🤥

یه بازی چندنفره‌ی تحت وب و فارسی برای دوستا و خانواده (از ۲ نفر به بالا)، روی گوشی یا لپ‌تاپ.
هر راند هر کی یه جمله درباره‌ی **هر چیزی** می‌نویسه: درباره‌ی خودش، دوستاش، یه واقعیت علمی یا یه نکته‌ی خفن،
و مخفیانه می‌گه این جمله **راسته یا دروغه**. بقیه، بدون اینکه بدونن جمله مال کیه، به هر جمله رأی می‌دن.
هر رأی اشتباه به جمله‌ی تو یه امتیاز برای توئه، و آخر بازی **هر کی بیشتر از همه رأی اشتباه گرفته باشه برنده‌ست.**
بعضی بازیکن‌ها بچه‌ان، پس کلمه‌ی بد ممنوعه: اسم یا جمله‌ای که کلمه‌ی بد داشته باشه قبول نمی‌شه.

## 📱 بازی با یک گوشی (بدون اینترنت)
اگه همه دور هم هستن، لازم نیست هر کی گوشی خودش رو بیاره. توی صفحه‌ی اول «بازی با یک گوشی» رو بزن، اسم
بازیکن‌ها (۲ تا ۲۰ نفر) و تعداد راندها رو انتخاب کن. بازی می‌گه «گوشی رو بده به سارا». سارا «من سارا
هستم» رو می‌زنه، جمله‌ش رو می‌نویسه و راست یا دروغ بودنش رو انتخاب می‌کنه و گوشی رو به نفر بعدی
می‌ده. رأی دادن هم همین‌طوریه. این حالت تایمر
نداره و افشاگری و جدول امتیاز رو همه با هم روی همون گوشی می‌بینن.

این حالت کامل روی خود گوشی اجرا می‌شه، مثل «آش»: کافیه سایت یه بار با اینترنت باز بشه، بعد از اون بدون
اینترنت هم باز می‌شه و کار می‌کنه (فایل‌ها با service worker روی گوشی ذخیره می‌شن). با «افزودن به صفحه‌ی
اصلی» مرورگر هم مثل یه اپ نصب می‌شه. بازی بعد از هر قدم روی گوشی ذخیره می‌شه، پس رفرش یا بستن صفحه
بازی رو خراب نمی‌کنه.

## خروج و شروع دوباره
وسط بازی دکمه‌ی «⋯» بالای صفحه یه منو باز می‌کنه:
- **🔁 شروع دوباره:** امتیازها پاک می‌شه. توی بازی یک‌گوشی از راند اول شروع می‌شه؛ توی بازی آنلاین فقط
  میزبان می‌تونه بزنه و همه برمی‌گردن به لابی.
- **🚪 خروج از بازی:** برمی‌گردی به صفحه‌ی اول.

## تنظیمات (دست میزبان، توی لابی)
تعداد راندها (۱ تا ۳۰، پیش‌فرض ۳)، زمان نوشتن (۱۵ تا ۳۰۰ ثانیه، پیش‌فرض ۹۰)، زمان رأی دادن
(۱۰ تا ۱۸۰ ثانیه، پیش‌فرض ۶۰) و حداکثر بازیکن (۲ تا ۵۰، پیش‌فرض ۱۰). توی بازی یک‌گوشی فقط تعداد راندها
انتخاب می‌شه و تایمر نداره.

## روند بازی
1. **لابی:** یه نفر اتاق می‌سازه و یه کد ۴ حرفی می‌گیره (یا لینک دعوت رو می‌فرسته). میزبان 👑 تنظیمات رو انتخاب می‌کنه.
2. **نوشتن:** هر کی یه جمله می‌نویسه (تا ۱۶۰ حرف) و انتخاب می‌کنه «✅ راسته» یا «❌ دروغه». فقط خودش می‌دونه.
3. **رأی دادن:** همه‌ی جمله‌ها بدون اسم و با ترتیب تصادفی نشون داده می‌شن. هر کی به جمله‌های بقیه رأی می‌ده: راسته یا دروغه؟
4. **افشاگری:** جمله‌ها یکی‌یکی رو می‌شن: مال کی بود، راست بود یا دروغ، و کیا گول خوردن.
5. **امتیاز:** هر رأی اشتباه به جمله‌ی تو = ۱ امتیاز 😈 برای تو. بعد از هر راند جدول جمله‌ها و امتیازها میاد.
6. **آخر بازی:** هر کی بیشترین رأی اشتباه رو گرفته برنده‌ست و با کانفتی معرفی می‌شه. دکمه‌ی «بازی دوباره» هم هست.

## اجرای محلی
نیاز: Node.js نسخه‌ی ۱۸ یا بالاتر.

```bash
npm install
npm start
```
بعد `http://localhost:3000` رو باز کن.

## بانک سؤال (فعلاً استفاده نمی‌شه)
سؤال‌های کلمه‌ای و داستان‌هایی که برای نسخه‌ی قبلی بازی جمع شده بودن (۱۰۰ کلمه‌ای، ۱۰۰ داستانی و ۵۰ داستان
دروغ) هنوز توی `data/bank.json` هستن، ولی بازی الان ازشون استفاده نمی‌کنه و جمله‌ها رو خود بازیکن‌ها می‌نویسن.

## وصل شدن دوستان
**شبکه‌ی خونه (یه وای‌فای):** روی کامپیوتری که سرور روشه IP محلی رو پیدا کن (ویندوز: `ipconfig`، مک/لینوکس: `ifconfig` یا `ip a`)،
مثلاً `192.168.1.20`. دوستا توی مرورگر گوشی `http://192.168.1.20:3000` رو باز می‌کنن. اگه وصل نشد، به فایروال اجازه‌ی پورت ۳۰۰۰ رو بده.

**از طریق اینترنت (موقت):** یه تونل بساز، مثلاً:
```bash
npx cloudflared tunnel --url http://localhost:3000
```
یا `ngrok http 3000`. آدرس https که می‌ده رو برای دوستا بفرست.

## دیپلوی رایگان
سرور WebSocket همیشه‌روشن لازم داره، پس GitHub Pages (مثل آش) کار نمی‌کنه. گزینه‌های رایگان:
- **Render.com** (Web Service رایگان): با فایل `render.yaml` از New ← Blueprint ریپو رو انتخاب کن و Apply بزن (یا دستی: Build `npm install`، Start `npm start`). بعد از بی‌کاری می‌خوابه و اولین باز شدن چند ثانیه طول می‌کشه.
- **Koyeb** یا **Fly.io**: هر دو WebSocket رو پشتیبانی می‌کنن.

چون وضعیت اتاق‌ها توی حافظه‌ست، فقط **یه** نسخه از سرور اجرا کن. اتاق‌های خالی بعد از ۵ دقیقه پاک می‌شن.

## ساختار
- `server.js`: سرور Express و Socket.IO برای بازی آنلاین؛ مرجع وضعیت اتاق‌ها و همه‌ی تایمرها
- `public/core.js`: قانون‌های بازی که هم سرور و هم مرورگر ازش استفاده می‌کنن: نرمال‌سازی فارسی (ی/ي، ک/ك،
  فاصله و نیم‌فاصله، عددها)، تشخیص جواب نزدیک، فیلتر کلمه‌ی بد، رأی‌ها، امتیازدهی و جدول هر راند
- `public/app.js`: رابط کاربری، و موتور بازی یک‌گوشی که کامل روی گوشی اجرا می‌شه
- `public/sw.js`: ذخیره‌ی فایل‌ها روی گوشی برای اجرای بدون اینترنت
- `data/bank.json`: بانک سؤال‌ها و داستان‌های قدیمی (فعلاً استفاده نمی‌شه)؛ `data/blocklist.json`: فهرست کلمه‌های بد فقط به شکل هش

رفرش یا قطع و وصل شدن: با شناسه‌ی ذخیره‌شده توی `localStorage` با همون اسم و امتیاز برمی‌گردی. اگه میزبان بره، میزبانی به نفر بعدی می‌رسه.
