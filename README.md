# آیا این داستان واقعیست؟ 🤥

### 🎮 [همین الان بازی کن](https://sajadzmani.github.io/Aya-In-Dastan-vagheist/)

یه بازی فارسی برای دوستا و خانواده که دور هم با **یه گوشی** بازی می‌کنن (۲ تا ۲۰ نفر).
یه جمله بگو، بقیه رو گول بزن!

## چطوری بازی کنیم؟
1. **شروع:** اسم بازیکن‌ها و تعداد راندها رو بنویس و «شروع بازی» رو بزن.
2. **نوشتن:** گوشی دست‌به‌دست می‌چرخه. هر کی نوبتش شد، یه جمله درباره‌ی **هر چیزی** می‌نویسه:
   درباره‌ی خودش، دوستاش، یه واقعیت علمی یا یه نکته‌ی خفن. بعد مخفیانه انتخاب می‌کنه
   **«✅ راسته»** یا **«❌ دروغه»**. فقط خودش می‌دونه!
3. **رأی دادن:** وقتی همه نوشتن، گوشی دوباره می‌چرخه. هر کی به جمله‌های بقیه رأی می‌ده، بدون اینکه
   بدونه جمله مال کیه: راسته یا دروغه؟
4. **افشاگری:** جمله‌ها یکی‌یکی رو می‌شن: مال کی بود، راست بود یا دروغ، و کیا گول خوردن 😂
5. **امتیاز:** هر کی به جمله‌ی تو رأی اشتباه بده، **یه امتیاز 😈** برای تو.
6. **برنده:** آخر بازی هر کی بیشتر از همه بقیه رو گول زده باشه، برنده‌ست! 🎉

## قانون‌ها
- همه باید جمله بنویسن و به همه‌ی جمله‌ها رأی بدن؛ هیچ‌کس رد نمی‌شه.
- بازی تایمر نداره و هر مرحله با دکمه‌ی «بعدی» جلو می‌ره.
- کلمه‌ی بد ممنوعه 😇
- وسط بازی با دکمه‌ی «⋯» می‌تونی بازی رو از اول شروع کنی یا ازش بیرون بیای.
