# آیا این داستان واقعیست؟ 🤥

یه بازی فارسی برای دوستا و خانواده که دور هم با **یه گوشی** بازی می‌کنن (۲ تا ۲۰ نفر).
هر راند هر کی یه جمله درباره‌ی **هر چیزی** می‌نویسه: درباره‌ی خودش، دوستاش، یه واقعیت علمی یا یه نکته‌ی خفن،
و مخفیانه می‌گه این جمله **راسته یا دروغه**. بقیه، بدون اینکه بدونن جمله مال کیه، به هر جمله رأی می‌دن.
هر رأی اشتباه به جمله‌ی تو یه امتیازه، و آخر بازی **هر کی بیشتر از همه رأی اشتباه گرفته باشه برنده‌ست.**
بعضی بازیکن‌ها بچه‌ان، پس کلمه‌ی بد ممنوعه: جمله‌ای که کلمه‌ی بد داشته باشه قبول نمی‌شه.

## بازی کردن

آنلاین (بعد از روشن کردن GitHub Pages): **https://sajadzmani.github.io/Aya-In-Dastan-vagheist/**

ساختن (build) لازم نداره. `index.html` رو توی مرورگر باز کن (از روی خود فایل هم کار می‌کنه)، یا پوشه رو با
یه سرور ساده باز کن (`python3 -m http.server`) و برو به `http://localhost:8000`.

## روند بازی
1. **شروع:** اسم بازیکن‌ها (۲ تا ۲۰ نفر) و تعداد راندها (پیش‌فرض ۳) رو بنویس و «شروع بازی» رو بزن.
   اسم‌ها برای دفعه‌ی بعد ذخیره می‌شن.
2. **نوشتن:** بازی می‌گه «گوشی رو بده به سارا». سارا «من سارا هستم» رو می‌زنه، جمله‌ش رو می‌نویسه (تا ۱۶۰ حرف)
   و انتخاب می‌کنه «✅ راسته» یا «❌ دروغه»، بعد گوشی رو به نفر بعدی می‌ده.
3. **رأی دادن:** وقتی همه نوشتن، «بریم رأی بدیم» رو بزنید. گوشی دوباره می‌چرخه و هر کی به جمله‌های بقیه
   (بدون اسم و با ترتیب تصادفی) رأی می‌ده: راسته یا دروغه؟
4. **افشاگری:** جمله‌ها با دکمه‌ی «بعدی» یکی‌یکی رو می‌شن: مال کی بود، راست بود یا دروغ، و کیا گول خوردن.
5. **امتیاز:** هر رأی اشتباه به جمله‌ی تو = ۱ امتیاز 😈. بعد از هر راند جدول جمله‌ها و امتیازها میاد.
6. **آخر بازی:** هر کی بیشترین رأی اشتباه رو گرفته برنده‌ست و با کانفتی معرفی می‌شه. «بازی دوباره» با همون
   اسم‌ها از اول شروع می‌کنه.

**بازی تایمر نداره و هیچ‌وقت خودش جلو نمی‌ره:** همه باید جمله‌شون رو بنویسن و به همه‌ی جمله‌ها رأی بدن، و هر
مرحله فقط با دکمه‌ی «بعدی» جلو می‌ره.

وسط بازی دکمه‌ی «⋯» بالای صفحه یه منو باز می‌کنه: **🔁 شروع دوباره** (امتیازها پاک می‌شه و از راند اول با همین
اسم‌ها شروع می‌شه) یا **🚪 خروج از بازی** (برگشت به صفحه‌ی اسم‌ها).

بازی بعد از هر قدم توی `localStorage` مرورگر ذخیره می‌شه، پس رفرش یا بستن صفحه بازی رو خراب نمی‌کنه.

## بدون اینترنت
کافیه سایت یه بار با اینترنت باز بشه؛ بعد از اون بدون اینترنت هم باز می‌شه و کار می‌کنه (فایل‌ها با service
worker روی گوشی ذخیره می‌شن). با «افزودن به صفحه‌ی اصلی» (Add to Home Screen) مرورگر هم مثل یه اپ نصب می‌شه.

## انتشار روی GitHub Pages
1. Settings ← Pages ← Build and deployment ← Source: **Deploy from a branch**، شاخه‌ی `main` و پوشه‌ی
   `/ (root)` رو انتخاب کن و Save رو بزن. (با اکانت رایگان، ریپو باید public باشه.)
2. بعد از یکی دو دقیقه بازی روی `https://sajadzmani.github.io/Aya-In-Dastan-vagheist/` بالاست. فایل `.nojekyll`
   باعث می‌شه گیت‌هاب فایل‌ها رو همون‌طوری که هستن نشون بده.

## ساختار
- `index.html`، `style.css`: صفحه و طراحی (فونت وزیرمتن، راست‌به‌چپ، مخصوص گوشی)
- `app.js`: صفحه‌ها و موتور بازی (نوبت‌ها، ذخیره روی گوشی)
- `core.js`: قانون‌های بازی: نرمال‌سازی فارسی، فیلتر کلمه‌ی بد، رأی‌ها، امتیازدهی و جدول هر راند
- `data/blocklist.js`: فهرست کلمه‌های بد، فقط به شکل هش (هیچ کلمه‌ی بدی توی کد نوشته نشده)
- `sw.js`، `manifest.webmanifest`، `icon.svg`: اجرای بدون اینترنت و نصب روی صفحه‌ی اصلی گوشی
- `data/bank.json`: سؤال‌ها و داستان‌های نسخه‌ی قبلی بازی (۱۰۰ کلمه‌ای، ۱۰۰ داستانی و ۵۰ داستان دروغ)؛
  فعلاً استفاده نمی‌شه
